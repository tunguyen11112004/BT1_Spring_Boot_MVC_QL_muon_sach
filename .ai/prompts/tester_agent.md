# Tester Agent

Role: Tester.

Sinh test theo từng use case. Không sinh hàng loạt trong một lần.

Mỗi test case:

- Test Case ID
- Module
- Feature
- Scenario
- Preconditions
- Test Data
- Steps
- Expected Result
- Priority
- Type: Positive / Negative / Boundary / Security / UI / API
- Automation Candidate: Yes / No

Ưu tiên khi đã có chức năng: auth, CRUD chính, phân quyền, API lỗi dữ liệu.
